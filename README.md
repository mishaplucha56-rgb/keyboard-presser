# ⌨️ On-Screen Virtual Keyboard (CustomTkinter + PyAutoGUI)

Стильная на экранная виртуальная клавиатура с полупрозрачным GUI интерфейсом, написанная на **Python** с использованием библиотек **CustomTkinter** и **PyAutoGUI**. 

Программа эмулирует физические нажатия клавиш клавиатуры в операционной системе при клике по интерактивным кнопкам.

---

## ✨ Особенности

* 🎨 **Современный UI**: Использование библиотеки `CustomTkinter` с кастомной цветовой палитрой и эффектами наведения.
* 👻 **Полупрозрачность**: Окно программы имеет настраиваемую прозрачность (`alpha = 0.85`), не перекрывая полностью рабочий стол.
* ⚡ **Эмуляция ввода**: Реалистичная эмуляция нажатий через `PyAutoGUI` (поддерживает буквенно-цифровые клавиши, `Space`, `Enter`, `Esc`, `Tab`, `Shift`, `Ctrl` и др.).
* 📐 **Фиксированный макет**: Полноразмерная раскладка клавиатуры с защитой от изменения размеров окна.
